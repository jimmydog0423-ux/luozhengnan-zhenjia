# 羅正男：真假

這是一個純單機 HTML5 Canvas 垂直切片，不需要資料庫、不需要 Node.js、不需要後端。

## 這版不是上一版的規則房間

完整流程：

1. 2026「頭貼軍團」動作逃脫開場
2. 2013 北投自由探索
3. 2014 四十包零傳說互動段落
4. 8 張牌組建構
5. 三場限時爬梯牌局
6. 高疲勞晉級後挑戰
7. 回到 2026，對抗會模仿玩家牌組偏好的「羅正男分身」

## 操作

- WASD / 方向鍵：移動
- Shift：衝刺
- 空白鍵：動作 / 拆包
- E：互動
- 滑鼠：卡牌操作
- Enter：牌局結束回合 / 牌組確認
- Esc：暫停

## 啟動

直接雙擊 `index.html` 即可。

若瀏覽器對本機檔案限制較嚴格，可執行：

```bat
啟動遊戲.bat
```

然後打開：

```text
http://localhost:8080
```

## 專案特色

- 全部原生 HTML / CSS / JavaScript
- 無任何外部 CDN
- Canvas 2D
- WebAudio 合成音效
- CRT / glitch / scanline 視覺
- 自製高瘦比例像素角色，不使用真人肖像
- 多玩法切換：動作探索 / 拆包 / 組牌 / 限時卡牌戰 / 動作 Boss
- `localStorage` 保存通關、死亡、牌組與最佳時間
- 2026 最終分身會依玩家牌組中的 Rush 偏好調整彈幕數量
