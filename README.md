# 羅正男：紅色學校

這是一個「一房一圖」的單機校園靈異調查 RPG 垂直章節。

## 核心內容

- 主角：羅正男
- 搭檔：薛喜
- 地點：紅色學校
- 每個房間都是獨立完整場景，不再一次看到整張地圖
- `M` 開啟校園平面圖，可對已探索安全區快速移動
- 房間加入大量可調查小物件與環境敘事
- 多條調查路線
- 線索筆記
- RPG 式左右大型人物對話
- 角色專屬互動遊戲
- 多個 BAD END
- Normal End
- True Route
- 最終 Boss：超負荷（虛構超自然版本）
- 隱藏 Boss：金字塔紹安（虛構超自然角色，不代表現實人物）

## NPC 專屬互動

### 中指通
六軌節奏挑戰：
`A S D J K L`

### TOYZ
紙捲競速：
- A / D 控制鬆緊
- Space 捲動
- 要同時兼顧速度與品質

### 統神
由薛喜上場的簡化讀人撲克：
- 不涉及真錢
- 讀表情與行為
- 1 / 2 / 3 做判斷

## 調查小遊戲

- 班級照片找異常
- 紫外線掃描
- 電腦啟動順序推理
- NPC 專屬遊戲
- 房間數量／外牆數量矛盾
- 假薛喜分支

## Boss

### 大肥哥超負荷
三階段：
1. 左右精準防反
2. 五線聊天室過載
3. 移動＋反擊混合

如果沒有蒐集三個「心願碎片」，擊敗後只會進 Normal End。

### 金字塔紹安
完成超負荷心願後才會解鎖：
1. 前面探索內容的快速推理
2. 三線躲避＋反擊

## BAD END

目前包含：
- 直接離校
- 相信假薛喜
- 超負荷戰敗
- 金字塔戰敗

## 操作

- WASD / 方向鍵：移動
- E：調查／對話
- Shift：快走
- M：地圖／快速移動
- Q：案件筆記
- Esc：返回／暫停
- 對話：Space / Enter
- 選項：上下＋Enter
- 各小遊戲會在畫面上顯示自己的按鍵

## 啟動

直接開啟 `index.html`。

若瀏覽器對本機檔案限制較嚴格：

```bat
啟動遊戲.bat
```

然後開：

```text
http://localhost:8080
```
