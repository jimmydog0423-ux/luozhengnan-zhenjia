# 羅正男：宿舍失蹤事件

《羅正男：真假》的 Case 01 垂直切片。

這版的設計重點不是把羅正男的人生事件做成一堆小遊戲，而是建立固定的核心玩法：

- 大型宿舍地圖自由探索
- RPG 式左右大型人物立繪＋底部對話框
- NPC 證詞
- 實際操作直播電腦
- 自由輸入聊天室搜尋關鍵字
- 門禁與時間差推理
- 錯誤推理可繼續遊戲
- 四路監視器追蹤與時間偏移
- 黑暗潛行／追逐
- 手電筒會提高敵人追蹤速度
- 配電箱恢復電力
- 章末「五十大謊言」資訊分類 Boss
- localStorage 保存通關與失誤紀錄

## 啟動

直接開啟 `index.html`。

如果瀏覽器限制本機執行，可執行：

```bat
啟動遊戲.bat
```

然後開：

```text
http://localhost:8080
```

## 操作

- WASD / 方向鍵：移動
- E：對話／調查
- Shift：快走
- Q：案件筆記
- F：黑暗時開關手電筒
- Esc：暫停／離開介面
- 電腦介面：依畫面提示使用數字鍵、方向鍵、Enter、Backspace
- 監視器：1～4 切換鏡頭、左右鍵調整分鐘、Space 標記重要畫面
- 章末分類：1～4

## 建議調查方式

本作刻意不提供完整任務箭頭。第一輪建議：

- 先與宿舍內的人交談。
- 比對「記憶時間」與「系統時間」。
- 電腦搜尋不是固定按鈕答案，可自己輸入具體時間或事件。
- 門禁紀錄只代表「卡」經過，不等於「人」經過。
- 監視器的每個鏡頭時間未必同步。
- 如果推理錯，可以繼續走錯誤方向，不會立即判定失敗。
