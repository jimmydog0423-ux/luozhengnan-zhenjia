# 失序地城：規則牢獄

一個純前端、純單機的 2D 動作冒險 Prototype。

## 啟動方式

最簡單：

1. 解壓縮。
2. 直接開啟 `index.html`。

如果瀏覽器對本機檔案有限制，可在資料夾內執行：

```bash
python -m http.server 8080
```

然後開啟：

```text
http://localhost:8080
```

## 操作

- WASD / 方向鍵：移動
- Shift：Dash
- 空白鍵 / 滑鼠左鍵：攻擊
- R：重開目前房間
- Esc：暫停

## 現有內容

- 10 個房間
- 3 種普通敵人
- 1 隻 Boss：典獄長
- Dash / 攻擊 / 無敵幀
- 敵人追擊與彈幕
- 房間碰撞與出口條件
- 壓力板謎題
- 假門陷阱
- 9 種以上規則
- Boss 動態改寫規則
- `localStorage` 死亡記憶
- Boss 會根據死亡次數改變開場台詞
- 通關與最佳死亡數紀錄
- 不需要 Node.js、不需要資料庫、不需要後端

## 規則機制

目前包含：

- 禁止奔跑
- 禁止攻擊
- 禁止停止
- 不可殺生
- 禁止向左
- 移動會受傷
- 不得面向典獄長
- 禁止重複動作
- 禁止進入右半場
- 一擊死亡（已預留）
